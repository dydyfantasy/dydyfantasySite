### Points d'attention techniques relevés

- **Double meta description après JS** : `root.jsx` rend une description statique dans `<head>` ; `react-helmet` ajoute la sienne à côté sans la retirer (Helmet ne gère que ses propres balises `data-react-helmet`). Déjà le cas avec l'ancien `index.html`, non relevé au précédent audit. Google choisit alors l'une des deux ou réécrit le snippet. Vérification : DevTools > Console, `document.querySelectorAll('meta[name=description]').length` sur `/contact` (attendu 1, probablement 2).
- **Title** : le `<title>` est désormais rendu par React dans `Layout` et modifié par Helmet via `document.title`. Rien d'anormal dans le code, mais à contrôler après navigation interne. Vérification : naviguer `/` → `/contact` → `/prestations` et lire `document.title` à chaque étape.
- **Helmet et pré-rendu (étape 4)** : le pré-rendu de React Router ne collecte pas les balises `react-helmet`. Si Helmet est conservé, les HTML pré-rendus contiendront le title et la description génériques de `Layout`, sans canonical ni OG. Il faudra passer aux exports `meta` des routes (rendus par `<Meta />`, déjà présent dans `Layout`) ou aux balises `<title>`/`<meta>` natives de React 19, et retirer le title/description statiques de `Layout` pour éviter les doublons.

## Recommandations priorisées

### 1. Ajouter la 301 `/notre-approche` → `/mon-approche` dans `.htaccess` au plus tard au déploiement de l'étape 2 (impact : fort, urgent avant mise en ligne)
- **Mécanisme** : aujourd'hui `/notre-approche` (290 impressions, 2 clics) renvoie un 200 sur une page vide. Après déploiement de l'étape 2, elle rendra la page 404 avec `noindex`. Google la retirera de l'index sans transmettre ses signaux (liens, historique) à `/mon-approche`. Une 301 indique que le contenu a déménagé et consolide ces signaux sur la nouvelle URL. Cette règle Apache ne dépend pas du pré-rendu : rien n'oblige à attendre l'étape 4. Couvrir aussi la variante `www.` (déjà traitée par la règle www existante, à condition que la 301 ne crée pas de double saut).
- **Vérification** : `curl -sI https://dydyfantasy.fr/notre-approche` → `301` + `Location: https://dydyfantasy.fr/mon-approche` ; `curl -sI https://www.dydyfantasy.fr/notre-approche` → au plus 2 sauts finissant sur `/mon-approche` (`curl -sIL`). Dans GSC, l'URL passe en « Page avec redirection ».

### 2. Pré-rendre chaque route (étape 4) en migrant les meta hors de `react-helmet` (impact : fort)
- **Mécanisme** : Googlebot lit d'abord le HTML brut, puis rend le JS plus tard via une file d'attente. Aujourd'hui toutes les URL montrent le même title et 0 mot dans cette première lecture, et les aperçus WhatsApp/Facebook (qui n'exécutent pas le JS) n'ont ni titre propre ni image. Le pré-rendu n'apporte ce gain que si title, description, canonical et OG sont produits pendant le rendu serveur : `react-helmet` ne l'est pas par React Router. Il faut donc des exports `meta` par route (ou les balises natives React 19) et supprimer les balises statiques de `Layout`, ce qui supprime aussi la double description.
- **Vérification** : après build, `build/client/contact/index.html` existe et `grep -c "<h1" build/client/contact/index.html` = 1 ; `grep -o "<title>[^<]*" build/client/*/index.html` donne un title différent par route ; `grep -c 'name="description"'` = 1 par fichier ; GSC > Inspection de l'URL > « Afficher la page explorée ».

### 3. Adapter `.htaccess` au pré-rendu : slash final, vrai 404 (impact : fort, étape 4)
- **Mécanisme** : avec un fichier `contact/index.html`, Apache (`mod_dir`, `DirectorySlash On` par défaut) redirige `/contact` vers `/contact/` en 301, ce qui contredirait le canonical et le sitemap (sans slash) : signaux contradictoires et redirection sur chaque URL du sitemap. Il faut soit désactiver `DirectorySlash` et réécrire `/contact` vers `contact/index.html`, soit pré-rendre en `contact.html`. Les URL inconnues doivent renvoyer un code 404 réel (avec la page NotFound comme `ErrorDocument`), car un 200 reste une soft 404 que Google signale et explore inutilement ; le `noindex` posé par JS n'est qu'un palliatif.
- **Vérification** : `curl -sI https://dydyfantasy.fr/contact` → 200 sans `Location` ; `curl -sI https://dydyfantasy.fr/contact/` → 301 vers `/contact` ; `curl -sI https://dydyfantasy.fr/page-inexistante-xyz` → 404 ; rapport GSC « Pages » sans « Soft 404 ».

### 4. Un seul JSON-LD `LocalBusiness` cohérent (impact : moyen)
- **Mécanisme** : Google rapproche les données structurées de l'entité (fiche locale, Knowledge Graph). Le bloc global est maintenant dans le HTML brut, mais `Home.jsx` en ajoute un second, contradictoire et sans `@id`. Fusionner dans `root.jsx` (un `@id` du type `https://dydyfantasy.fr/#business`, téléphone, `areaServed` réel : Haute-Garonne, Gers, Tarn, communes de l'ouest toulousain, `sameAs` normalisés sans `&locale=id_ID`) donne une entité unique et peut aider sur les requêtes « gers ».
- **Vérification** : Test des résultats enrichis / validator.schema.org sur `/` et `/contact` : un seul `LocalBusiness`, aucun avertissement.

### 5. Pages de l'architecture cible alignées sur les requêtes (impact : fort, plus long terme)
- **Mécanisme** : une page se classe sur une intention si elle la traite explicitement (title, H1, contenu). DJ (dj gers 179 imp.), Anniversaire (+ Gers), Team building / entreprise, Blind Test & Quiz, Mariage n'ont aucune page ; seule la home capte ces requêtes, en position 13-30. L'animation micro / speaker (117 imp.) peut s'appuyer sur la référence réelle Decathlon.
- **Vérification** : GSC > Performances, filtre par page, impressions et position sur ces requêtes après indexation ; chaque nouvelle route ajoutée au sitemap.

### 6. Titles, descriptions, Open Graph, `/privacy` (impact : moyen à faible)
- **Mécanisme** : le title est un signal de pertinence et, avec la description, détermine le CTR (`/prestations` : 342 imp., CTR 0,3 %). Au-delà de ≈ 60 / 160 car., Google tronque ou réécrit. Sans `og:image`, les partages WhatsApp/Facebook n'ont pas d'image. `/privacy` (title « Dydy Quiz ») est indexable et hors sujet : un `noindex` dans le HTML pré-rendu l'écarte.
- **Vérification** : longueurs mesurées dans les HTML pré-rendus ; débogueur de partage Facebook ; `grep noindex build/client/privacy/index.html`.
